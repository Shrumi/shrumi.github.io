Калькулятор прайса фотосалона

Инструкция администратора: первый запуск, работа с чеком, отчёт по кассе.

1. Первый запуск: включить макросы

Вся логика поиска и расчётов работает на макросах. Excel по умолчанию их блокирует — достаточно разрешить один раз:

  1. Меню Файл → Параметры Excel (кнопка внизу справа)
  2. Центр управления безопасностью
  3. Параметры центра управления безопасностью → Параметры макросов
  4. Выбрать «Включить все макросы» → ОК
  5. Перезапустить файл
Эта же инструкция продублирована на стартовом листе самого файла. При открытии Excel может показать жёлтую полосу «Включить содержимое» — нажмите её, это то же самое.

2. Добавление услуги в чек

Умный поиск по двум буквам

Начните вводить название — подойдут первые две буквы в любом регистре и любой раскладке клавиатуры:

ВводНайдёт
пе или gtПечать фото
ла или kfЛаминация

Стрелками ↑ ↓ выберите нужный вариант из списка — мышь не нужна. Это спасает при потоке клиентов и опечатках.

Количество

После выбора услуги курсор сам перескакивает в поле количества со значением «1». Изменить:

  • стрелками ↑ ↓ на клавиатуре,
  • кнопками-индикаторами рядом с полем,
  • вводом цифры + Enter.

Стоимость строки пересчитывается мгновенно.

3. Оформление заказа

Enter — сумма строки идёт в общий счёт, фокус переходит на следующую пустую строку. Многостраничный чек — непрерывная последовательность нажатий, без мыши и калькулятора.

4. Отчёт по кассе

  • Кнопка переноса отправляет чек дня в лист отчёта (общим списком; сортировка по категориям услуг — печать, сувенирка, фотокниги — планируется отдельным модулем).
  • На листе отчёта — кнопки суммирования: наличные, безналичные (карта) и общая сумма. Ежедневная сверка кассы и Z-отчёт — за секунды.

5. Очистка рабочего листа

Кнопки со знаком «Стоянка запрещена» быстро очищают текущий лист от ошибочных позиций перед новым заказом — без ручного удаления строк и сброса форматирования.

Что это даёт бизнесу

  • Скорость: расчёт клиента быстрее на 40–60% — без бумажных прайсов и карманного калькулятора.
  • Нулевая математика: исключены ошибки сложения чеков и сдачи.
  • Обучение за 5 минут: новый сотрудник осваивает интерфейс сразу.
  • Статистика: срез продаж за смену без дополнительных журналов.
